# Voicenotes Controls setup

No API token is required. Install and sign into the official Voicenotes Mac app.
Run Recording Setup and Status, grant the requested Accessibility permission, and
keep the app's Cancel Recording shortcut set to Option+C.

Start Recording opens Voicenotes and waits for its controls before starting.
Voicenotes 2.4.4 also supports Open Dictations, Open Meetings, Copy Latest Dictation,
Search Notes, and Ask AI. Search Notes accepts a query; Ask AI submits your prompt
once in a new chat. Both use the existing signed-in app session.

If an action reports uncertainty or times out, check Voicenotes before retrying.
